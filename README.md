# Telaffuz Koçu (Kotlin) - v2: kendi kelimelerini ekle / çıkar

Yeni: Ana ekran > "Kelime Ekle / Çıkar"
- Tek tek ekle: kelime + anlam (IPA, okunuş, örnek cümle isteğe bağlı)
- Toplu ekle: her satıra `kelime ; anlam ; IPA` yaz
- Sil: hazır ve kendi kelimeleri silebilirsin (hazır kelimeler geri getirilebilir)
- Kendi kelimelerin "Kelimeler" listesinde ve günlük çalışmada çıkar; yeni ve düşük puanlı kelimeler daha sık gelir
- Kelimeleri telefon okur, IPA yazmak zorunda değilsin

Tüm dosyalar `.github/workflows/` içindedir. APK: Actions > Build APK > Run workflow.
Bu sürümde konuşma tanıma Google servisini kullanır (internet gerekir).
